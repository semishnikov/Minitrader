# ЯРМАРКА ОТБЛЕСКОВ — дизайн-документ

Торговая игра на телефон. Не кликер, не симулятор: **аукцион + стол + дуэль**,
где ценность вещи зависит от того, что лежит на столе у тебя и у соперника.

Все числа ниже — из `src/core/engine.js`, это единственный источник правды.
Тест `npm test` (12 инвариантов) и `npm run balance` следят, чтобы они не разъехались с этим файлом.

## Столпы

1. **Каждое решение имеет цену.** Действия, слоты, монеты, репутация — всё конечно.
2. **Информация — тоже ресурс.** Разведка зала стоит денег, козырь соперника виден только
   через «Дознание» или вещь-линзу.
3. **Игрок решает дуэль, вещи дают инструменты.** Приёмы меняют математику, но не отменяют её.
4. **Нелинейность.** Одна вещь сильна по-разному: в тройке, с «хрупкой», с линзой,
   против меты соперника, в «Жадности».
5. **Честность.** Никаких скрытых бросков в пользу игрока. Все формулы открыты.

## Ход партии

| Фаза | Что происходит |
|---|---|
| **Утро · Торг** | 3 действия: аукцион дня, заказы домов, прилавок, ломбард, сделка дня |
| **Полдень · Стол** | 5–8 слотов, мастерская (спайка двух вещей в тройку), немая квота |
| **Вечер · Дуэли** | до 3 боёв: приём, ставка, разбор боя |
| **Ночь** | событие с ценой, долг ростовщику, инфляция, смена дня |
| 6 дней | Финал: «Большой молоток» — сила соперника от репутации, кассы и дня |

## Экономика

- Валюта одна — монеты `М`. Старт: **620 М**, репутация 20.
- Действий в день: **3**. Стоимость лотов кумулятивная: 1-й — 0 действия, 2-й — 1, дальше — 2.
- Слот: `60 + (слоты−5)·55 + день·6`, максимум 8.
- Мастерская: `24 + день·4`. Смена зала: `35 + день·8`. Слух: `30 + день·6`.
- Инфляция: **+0.22/день**, поднимает цену брокера, влияет на курс.
- Продажа: `1.08×` (+0.08 с брокером, +`min(0.14, реп/320)`).
- Ломбард: залог `0.7×`, выкуп +9%, срок 2 дня, иначе вещь уходит.
- Брокер: `55 + день·8 + инфляция·3`. Даёт +7% к прилавку, ночную комиссию
  `30 + день·9` **и раскрывает немую квоту** — он знает, что ищет город.

### Сделка дня

Одна на утро, действует только сегодня, появляется в ~78% дней. Четыре вида:

| Вид | Механика |
|---|---|
| Закрытый конверт | вещь не показана; цена 1.10–1.55× каталога; в 30% случаев это приманка |
| Связка «на сдачу» | две рядовые вещи за 0.55–0.80× их суммы |
| Редкость из-под прилавка | редкая вещь за 1.20–1.65× каталога |
| Займ у ростовщика | +120 М сейчас, вечером вернуть 145% или −8 репутации |

Сделка — не бесплатные деньги: переплата случается, и это видно в книге.

## Аукционы

Четыре стиля, у каждого своя логика ставки:

| Стиль | Старт | Правило |
|---|---|---|
| Голландский | `1.28–1.46×` ценности, падает `×0.865` за взгляд, пол `0.46×` | ждёшь — дешевле, но уведут |
| Слепой | `0.52–0.64×` | побеждаешь — платишь вторую ставку +1 |
| Лестница | `0.52–0.64×` | каждый следующий лот дороже и ценнее |
| Спорный | `0.52–0.64×` | боты торгуются вслух, цена ползёт |

Боты оценивают лот множителем **0.74–1.02** от скрытой ценности («туман зала»).
Поэтому ставка «старт + 1» выигрывает только ~26% — надо читать зал и торговаться.
Связки (два предмета в лоте) — около 24% лотов.

**Сигналы без утечки информации:** «просят дёшево / выше каталога» — отношение
текущей цены к каталогу; «зал прибавит / разгонится / торгов лёгкий» — жар аукциона.
Предел зала и скрытая ценность показываются только после платной разведки
`6 + 0.06·ценность` М.

## Вещи и стол

31 реликвия, 6 классов (янтарь, кость, фарфор, стекло, латунь, чернила),
4 редкости: рядовая → изящная → редкая → сказанная.

Сила стола: `сумма × (1 + 0.18·тройки + 0.12·все классы разные) × (1 + реп/500) × моды`.

**Характер вещи** — редкое свойство, которое работает в дуэли:

| Метка | Эффект |
|---|---|
| Хрупкая | +2 силы за каждую другую вещь своего класса на столе |
| Линза | показывает скрытый козырь соперника ещё до выбора приёма |
| Точность | +6 силы, если на столе есть тройка |
| Без имени | +3 репутации при победе |

## Заказы домов и немая квота

У каждого из 6 домов **свой класс** — это выучивается за пару партий:
Ашкрофт берёт янтарь, Молочник — фарфор, Архив — чернила, Верньер — латунь,
Стеклодувы — стекло, Склеп — кость.

- Заказ: награда `база·(2.0–2.5) + 45 + день·10`, репутация +2…+5.
- **Немая квота**: один дом тайно ищет вещь; угадаешь класс и редкость —
  получишь `120 + (редкость)·45` плюс премию `×(1 + (день−1)·0.12)` и +6 репутации.
  Брокер раскрывает, кто и что ищет. Без него — только догадка по вкусу дома.

## Дуэли

Соперник: твой стол `× [0.82, 0.95, 1.08] + 6 + 3·день`, разброс ±3%.
Пока соперник не изучен, виден коридор **±18%**.

Один приём за бой (7 вариантов, у каждого контрприём):

| Приём | Эффект | Винрейт в симуляции |
|---|---|---|
| Гнездо | +45% силы за 35 М | 89% |
| Обманка | сила соперника −15%, против «Хитрости» −25% | 78% |
| Башня | +28% при тройке, иначе +8% | 63% |
| Слово | отключает мету соперника | 50% |
| Немая сцена | полностью отключает скрытый приём | 42% |
| Дознание | раскрывает приём и карты, силы не меняет | 30% |
| Жадность | +18% силы, но проиграл — платишь вдвое | — |

Ставка: доля кассы (по умолчанию 15%). Победа: `ставка·0.9 + 35 + день·12`
(+`0.9·ставка` против «Жадности», +15 при нулевой ставке), репутация +3.
Поражение: `−ставка`, репутация −1. Ничья: 0, репутация +1.

После боя — **разбор**: из чего сложилась сила (стол, приём, козырь) и урок на следующий бой.

## Финал

`сила соперника = 70 + реп·0.9 + min(120, касса·0.05) + день·6`.
Очки: `касса + реп·8 + сданные вещи·2`, победа добавляет 700.

## Баланс (симулятор, `npm run balance`)

| Игрок | Очки | Побед в финале |
|---|---|---|
| Пассивный | 780 | 0% |
| Обычный | ~960 | 13% |
| Умный | 1079 | 15% |

Разрыв «пассивный → умный» ≈ +38% очков: механики вознаграждают решения, а не время в игре.

## Интерфейс

- `.app` не шире 520px, липкая шапка (день, репутация, касса), нижний док на 4 вкладки.
- Всё на одном экране: модалки — только шторки снизу, не новые страницы.
- Минимальная цель касания — **40px**; проверено на 360×640 (`npm run e2e`).
- Отклик: вибрация, синтезированный звук (WebAudio, без файлов), «+М» при каждом изменении.
- Сохранение в `localStorage` после каждого действия + код партии для переноса.

## Арт

Процедурная гравюра (`src/ui/art.js`): силуэт выбирается **по названию вещи**
(шестерня выглядит шестернёй, трубка — трубкой), плюс свой орнамент у каждого имени.
Ни одного растрового ассета: всё рисуется SVG из чисел.
