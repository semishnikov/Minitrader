# Экраны

Реальные скриншоты из игры (390×844, iPhone-подобный экран).

| Файл | Что показано |
|---|---|
| `screen-splash.png` | Вход: герб ярмарки, свод обещаний |
| `screen-rules.png` | Свод правил — те же числа, что в движке |
| `screen-market.png` | Утро: аукцион дня, лоты, сделка дня |
| `screen-bid.png` | Шторка ставки: ползунок, выгода, «разведать зал» |
| `screen-table.png` | Полдень: стол, сила, тройки, немая квота |
| `screen-duel-lobby.png` | Вечер: правила дуэлей |
| `screen-duel.png` | Дуэль: коридор силы соперника, скрытый приём |
| `screen-duel-moves.png` | Приёмы и ставка |
| `screen-duel-result.png` | Итог боя |
| `screen-ledger.png` | Книга: каждая монета и каждая ошибка |
| `screen-night.png` | Ночь: событие с выбором |

Арт реликвий — процедурная гравюра (`src/ui/art.js`): 6 классов × 3 силуэта,
36 уникальных названий, у каждого свой орнамент. Ни одного растрового ассета.
