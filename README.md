# Ярмарка Отблесков

Торговая игра на телефон: аукционы, складчины, ломбард, слухи и дуэли заказов.
Шесть дней, одна валюта — монеты, много разных схем заработка.

## Запуск

```bash
npx http-server . -p 8080 -c-1
# открыть http://localhost:8080
```

Игра — статичный сайт без сборки. Просто откройте `index.html` через любой
http-сервер (file:// не подойдёт из-за ES-модулей).

## Установка на телефон

Откройте адрес в мобильном браузере → «Добавить на главный экран».
Манифест и иконки на месте, приложение запускается в полноэкранном режиме.

## Что внутри

- `src/core/engine.js` — вся логика: рынок, боты, дуэли, ночные события, финал.
- `src/ui/` — интерфейс без фреймворков: экраны, шторки, звук, тактильный отклик.
- `src/ui/art.js` — процедурная гравировка реликвий (6 классов × 3 силуэта).
- `tests/balance.js` — прогон стратегий для проверки баланса.

## Проверка баланса

```bash
node tests/balance.js
```
