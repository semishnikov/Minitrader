# Ярмарка Отблесков

Торговая игра на телефон: аукционы, заказы домов, ломбард, сделка дня и дуэли.
Шесть дней, одна валюта — монеты `М`, много разных схем заработка.

## Запуск

```bash
npm run serve
# открыть http://localhost:8080
```

Игра — статичный сайт без сборки. Достаточно любого http-сервера
(`file://` не подойдёт из-за ES-модулей).

## Установка на телефон

Откройте адрес в мобильном браузере → «Добавить на главный экран».
Манифест и иконки на месте, приложение запускается в полноэкранном режиме.
Сохранение идёт в `localStorage` после каждого действия — можно закрывать вкладку.

## Правила в двух словах

- **Утро** — 3 действия: аукцион дня (4 стиля), заказы домов, прилавок, ломбард,
  сделка дня. Первый лот бесплатен по действиям, второй стоит 1, дальше — 2.
- **Полдень** — стол на 5–8 слотов. Тройка одного класса даёт +18% силы,
  все классы разные — ещё +12%. Мастерская спаивает две вещи в одну.
- **Вечер** — до 3 дуэлей. Один приём за бой, но перед боем видно прогноз
  по каждому приёму. Победа: `ставка·0.9 + 35 + день·12` (ставка — до трети кассы).
- **Ночь** — событие с ценой, инфляция, смена дня.
- **Финал** — последний торг: две ставки из трёх лотов (сила / репутация / касса),
  потом удар молотка.

Все числа открыты в «Своде правил» и совпадают с движком: экран правил читает их
из `engine.js`, а `npm test` проверяет 12 инвариантов экономики.

## Что внутри

- `src/core/engine.js` — вся логика: рынок, боты, дуэли, ночные события, финал.
- `src/data/cards.js` — 31 реликвия, 6 классов, 4 редкости, характер вещей, дома.
- `src/ui/` — интерфейс без фреймворков: экраны, шторки, звук, тактильный отклик.
- `src/ui/art.js` — процедурная гравюра: силуэт по названию вещи + свой орнамент.
  Ни одного растрового ассета.
- `docs/DESIGN.md` — дизайн-документ со всеми формулами.
- `docs/*.png` — реальные скриншоты всех экранов.

## Проверки

```bash
npm test          # 12 инвариантов экономики
npm run balance   # прогон стратегий (пассивный / обычный / умный / эксперт)
npm run e2e       # полная партия в настоящем браузере, нужен сервер на :8080
```

Ожидаемый разрыв по скиллу: пассивный 780 очков → обычный ~960 → умный 1575 → эксперт 1909.
Дуэли: обычный игрок выигрывает ~35%, эксперт — ~100% на отобранных боях.
